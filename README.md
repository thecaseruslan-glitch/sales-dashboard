# THE CASE Dashboards

Repository for THE CASE dashboard source files.

## Projects

- `sales-dashboard/` - sales-dashboard sales dashboard source.
- `purchase-dashboard/` - purchase-dashboard purchase dashboard source.
- `shared/` - shared notes/utilities when common logic is extracted.
- `docs/` - deployment notes, changelog, and operational documentation.
- `agent-notes/` - coding-agent rules and memory for this repository.

## Current Source Layout

Each dashboard currently has two Apps Script Web App files:

- `Code.gs` - backend Google Apps Script.
- `Index.html` - frontend HTML/CSS/JS.

Do not deploy changes to production without explicit approval from Руслан.
